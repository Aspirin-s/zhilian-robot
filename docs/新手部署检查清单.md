# 新手部署检查清单

## ✅ 部署前准备

### 1. 环境检查

- [ ] 已安装 Docker Desktop
  - Windows: 下载 https://www.docker.com/products/docker-desktop
  - 版本要求: Docker Desktop 4.0+
  
- [ ] Docker Desktop 正在运行
  - 查看系统托盘图标
  - 打开 Docker Desktop 确认状态为 "Running"

- [ ] Git 已安装
  - 命令: `git --version`
  - 如未安装: https://git-scm.com/downloads

### 2. 获取 DeepSeek API 密钥

- [ ] 注册 DeepSeek 账号
  - 网址: https://platform.deepseek.com/
  
- [ ] 创建 API 密钥
  - 进入 "API Keys" 页面
  - 点击 "Create API Key"
  - 复制密钥(格式: sk-xxxxxxxxxxxxxx)
  
- [ ] 确认账户有余额
  - 查看账户余额页面
  - 新用户通常有免费额度

## 📥 部署步骤

### 步骤 1: 克隆项目

```bash
git clone https://github.com/Aspirin-s/zhilian-robot.git
cd zhilian-robot
```

**检查点:**
- [ ] 命令执行无错误
- [ ] 当前目录下有 `docker-compose.yml` 文件

### 步骤 2: 配置环境变量

#### 2.1 复制配置文件

```bash
# Windows PowerShell
Copy-Item backend\.env.example backend\.env

# Linux/Mac
cp backend/.env.example backend/.env
```

**检查点:**
- [ ] `backend/.env` 文件已创建
- [ ] 文件大小约 1-2 KB

#### 2.2 编辑配置文件

使用任意文本编辑器打开 `backend/.env`，找到以下行:

```env
OPENAI_API_KEY=sk-08266faa1d184709878869666545ea9a
```

替换为你的 DeepSeek API 密钥:

```env
OPENAI_API_KEY=sk-你的实际密钥
```

**检查点:**
- [ ] 已替换 API 密钥
- [ ] 密钥以 `sk-` 开头
- [ ] 没有多余空格
- [ ] 保存文件

### 步骤 3: 启动服务

```bash
docker-compose up -d
```

**首次启动会下载镜像，需要 5-10 分钟，请耐心等待。**

**检查点:**
- [ ] 命令执行完成
- [ ] 看到 "Creating zhilian-xxx ... done" 消息
- [ ] 没有红色错误信息

### 步骤 4: 验证部署

#### 4.1 检查容器状态

```bash
docker-compose ps
```

**检查点:**
- [ ] 看到 9 个容器
- [ ] 所有容器 STATUS 列显示 "Up"
- [ ] 没有容器显示 "Exit" 或 "Restarting"

**9个容器清单:**
1. zhilian-frontend
2. zhilian-backend
3. zhilian-celery-worker
4. zhilian-celery-beat
5. zhilian-flower
6. zhilian-neo4j
7. zhilian-mongodb
8. zhilian-mysql
9. zhilian-redis

#### 4.2 检查后端日志

```bash
docker-compose logs --tail=20 backend
```

**检查点:**
- [ ] 看到 "Neo4j连接成功"
- [ ] 看到 "MongoDB连接成功"
- [ ] 看到 "Redis连接成功"
- [ ] 看到 "Application startup complete"
- [ ] 没有红色 ERROR 信息

#### 4.3 测试前端访问

打开浏览器，访问: http://localhost

**检查点:**
- [ ] 页面正常加载
- [ ] 看到 "智链机器人" 标题
- [ ] 顶部导航栏显示: 首页、数据管理、文本分析、图谱查询

#### 4.4 测试 API 文档

访问: http://localhost:8000/docs

**检查点:**
- [ ] Swagger UI 页面正常显示
- [ ] 看到 "FastAPI" 标题
- [ ] 看到多个 API 接口列表

## ❌ 常见问题

### 问题 1: 容器启动失败

**现象:** `docker-compose ps` 看到某个容器 STATUS 为 "Exit"

**解决方法:**

```bash
# 1. 查看该容器的日志
docker-compose logs 容器名称

# 2. 重启该容器
docker-compose restart 容器名称

# 3. 如果仍然失败，完全重启
docker-compose down
docker-compose up -d
```

### 问题 2: API 密钥错误

**现象:** 文本分析失败，提示 "API key invalid"

**解决方法:**

1. 重新检查 `backend/.env` 中的密钥
2. 确认密钥有效:
   - 登录 https://platform.deepseek.com/
   - 检查密钥状态
   - 确认账户余额
3. 重启后端:
   ```bash
   docker-compose restart backend
   ```

### 问题 3: 端口被占用

**现象:** 启动时提示 "port is already allocated"

**解决方法:**

1. 查看被占用的端口(通常是 80)
2. 编辑 `docker-compose.yml`
3. 修改端口映射:
   ```yaml
   frontend:
     ports:
       - "8080:80"  # 将前端改为 8080 端口
   ```
4. 重新启动:
   ```bash
   docker-compose down
   docker-compose up -d
   ```
5. 访问 http://localhost:8080

### 问题 4: Docker Desktop 未运行

**现象:** 执行命令提示 "Cannot connect to Docker daemon"

**解决方法:**

1. 打开 Docker Desktop 应用
2. 等待状态变为 "Running"
3. 重新执行 docker-compose 命令
