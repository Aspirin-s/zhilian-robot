# 快速开始指南

## 🚀 5分钟快速启动

### 前提条件

确保已安装:
- Python 3.8+
- Node.js 16+
- Git

### 步骤1: 克隆项目

```bash
git clone <your-repository-url>
cd zhilian-robot
```

### 步骤2: 初始化环境

运行初始化脚本:

```powershell
.\scripts\init.ps1
```

此脚本会自动:
- 创建Python虚拟环境
- 安装后端依赖
- 安装前端依赖
- 生成配置文件

### 步骤3: 配置数据库

#### 方案A: 使用Docker(推荐)

```bash
docker-compose up -d neo4j mongodb redis mysql
```

#### 方案B: 本地安装

手动安装并启动:
- Neo4j 5.20+
- MongoDB 8.x
- Redis 7.x
- MySQL 8.x

然后编辑 `backend/.env` 配置连接信息。

### 步骤4: 启动应用

```powershell
.\scripts\start.ps1
```

选择选项3"同时启动前后端"

### 步骤5: 访问系统

- 前端: http://localhost:3000
- 后端: http://localhost:8000
- API文档: http://localhost:8000/docs

## 🛠️ 开发模式

### 后端开发

```bash
cd backend
python -m venv venv
.\venv\Scripts\activate  # Windows
source venv/bin/activate  # Linux/Mac
pip install -r requirements.txt
python main.py
```

### 前端开发

```bash
cd frontend
npm install
npm run dev
```

## 🐳 Docker完整部署

一键启动所有服务:

```bash
docker-compose up -d
```

```bash
docker-compose logs -f
```

停止服务:

```bash
docker-compose down
```

## ⚙️ 配置说明

### 必需配置

编辑 `backend/.env`:

```env
# 数据库配置
NEO4J_URI=bolt://localhost:7687
NEO4J_USER=neo4j
NEO4J_PASSWORD=your_password

MONGODB_URI=mongodb://localhost:27017
REDIS_HOST=localhost
MYSQL_HOST=localhost

# API密钥(可选,用于大模型功能)
OPENAI_API_KEY=your_api_key
```

### 可选配置

- 爬虫延迟、并发数
- 日志级别
- CORS允许源

## ❓ 常见问题

**Q: 数据库连接失败?**

A: 检查数据库服务是否启动,配置文件中的连接信息是否正确。

**Q: 模型加载很慢?**

A: 首次运行会下载模型文件,请耐心等待。可配置国内镜像加速。

**Q: 前端显示404?**

A: 确保后端服务已启动,检查CORS配置。

**Q: 如何更新代码?**

A: 执行 `git pull` 后重新运行 `scripts/init.ps1`
