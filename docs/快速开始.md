# 快速开始指南

## 🚀 5分钟快速启动

### 前提条件

- **Docker Desktop** (推荐,支持 Windows/Mac/Linux)
- 或 **Python 3.8+** 和 **Node.js 18+** (本地开发)

## 方式一: Docker 一键部署 (推荐)

### 步骤1: 克隆项目

```bash
git clone https://github.com/Aspirin-s/zhilian-robot.git
cd zhilian-robot
```

### 步骤2: 配置环境变量

#### 2.1 复制配置文件

**首次部署必须先复制配置文件:**

```bash
# Windows PowerShell
Copy-Item backend\.env.example backend\.env

# Linux/Mac
cp backend/.env.example backend/.env
```

#### 2.2 配置 DeepSeek API（重要）

编辑 `backend/.env` 文件,修改以下配置:

```env
# DeepSeek API 配置（必须修改）
OPENAI_API_KEY=sk-xxxxxxxxxxxxxx  # 替换为你的 DeepSeek API 密钥
OPENAI_API_BASE=https://api.deepseek.com
OPENAI_MODEL=deepseek-chat
```

> 💡 **获取 API 密钥**: 
> 1. 访问 https://platform.deepseek.com/
> 2. 注册/登录账号
> 3. 进入 "API Keys" 页面
> 4. 创建新密钥并复制

#### 2.3 数据库配置（已预配置，可选修改）

数据库密码已在 Docker 和配置文件中统一设置为 `password123`，如需修改:

```env
# 数据库配置（Docker 容器默认值）
NEO4J_PASSWORD=password123      # Neo4j 图数据库密码
MONGODB_URI=mongodb://admin:password123@mongodb:27017
MYSQL_PASSWORD=password123      # MySQL 数据库密码
```

**注意**: 如果修改密码，需要同步修改 `docker-compose.yml` 中对应的环境变量。

### 步骤3: 启动所有服务

```bash
docker-compose up -d
```

等待几分钟,Docker 会自动拉取镜像并启动所有服务。

### 步骤4: 验证部署

#### 4.1 检查容器状态

```bash
# 查看所有容器状态
docker-compose ps
```

**预期结果**: 应该看到 9 个容器全部显示 `Up` 状态:

```
NAME                   STATUS
zhilian-frontend       Up
zhilian-backend        Up
zhilian-celery-worker  Up
zhilian-celery-beat    Up
zhilian-flower         Up
zhilian-neo4j          Up
zhilian-mongodb        Up
zhilian-mysql          Up
zhilian-redis          Up
```

#### 4.2 检查后端服务

```bash
# 查看后端启动日志（最后20行）
docker-compose logs --tail=20 backend
```

**成功标志**: 看到以下日志表示启动成功:
```
✓ Neo4j连接成功
✓ MongoDB连接成功
✓ Redis连接成功
INFO: Uvicorn running on http://0.0.0.0:8000
INFO: Application startup complete
```

#### 4.3 测试 API 接口

```bash
# Windows PowerShell
Invoke-WebRequest http://localhost:8000/docs

# Linux/Mac 或 Git Bash
curl http://localhost:8000/docs
```

**成功标志**: 返回 HTTP 200 状态码。

#### 4.4 访问前端页面

打开浏览器访问 http://localhost ，应该能看到智链机器人的主页。

**如果以上检查都通过，部署成功！🎉**

### 步骤5: 访问系统

**等待所有容器启动完成（约1-2分钟），然后访问:**

| 服务 | 地址 | 用户名 | 密码 | 说明 |
|------|------|--------|------|------|
| **前端界面** | http://localhost | - | - | React应用主界面 |
| **后端API** | http://localhost:8000 | - | - | FastAPI服务 |
| **API文档** | http://localhost:8000/docs | - | - | Swagger UI交互文档 |
| **任务监控** | http://localhost:5555 | - | - | Celery Flower面板 |
| **Neo4j界面** | http://localhost:7474 | neo4j | password123 | 图数据库管理 |

**首次访问 Neo4j 注意事项:**
1. 首次登录会要求修改密码
2. 如不想修改，请在 `docker-compose.yml` 中设置 `NEO4J_AUTH=none`
3. 或者登录后设置新密码，并同步更新 `backend/.env` 中的 `NEO4J_PASSWORD`

## 方式二: PowerShell 脚本启动 (Windows)

### 步骤1: 初始化环境

```powershell
# 进入项目目录
cd zhilian-robot

# 运行初始化脚本
.\scripts\init.ps1
```

此脚本会自动:
- 检查系统环境
- 创建Python虚拟环境
- 安装后端依赖
- 安装前端依赖

### 步骤2: 启动服务

```powershell
# 运行启动脚本
.\scripts\start.ps1
```

选择菜单选项:
- `1` - 仅启动后端
- `2` - 仅启动前端
- `3` - 同时启动前后端 (推荐)
- `4` - 启动Docker数据库服务
- `5` - 停止所有服务

## 首次使用指南

### 1. 访问首页

打开浏览器访问 http://localhost ,您会看到智链机器人的欢迎页面。

### 2. 数据管理

点击导航栏的 **"数据管理"**:

1. **查看RSS源**: 系统已预配置4个RSS订阅源
2. **立即更新**: 点击"立即更新"按钮,触发RSS数据采集
3. **查看文章**: 采集完成后,在文章列表中查看数据
4. **任务历史**: 查看采集任务的执行记录

### 3. 文本分析

点击导航栏的 **"文本分析"**:

1. **输入文本**: 在文本框中输入产业链相关内容
2. **加载示例**: 或点击"加载示例文本"查看示例
3. **分析文本**: 点击"分析文本"按钮,使用DeepSeek大模型分析
4. **查看结果**: 
   - 提取的实体(企业、产品、技术、人物、地点)
   - 提取的关系(供应商、合作、投资等)
5. **保存图谱**: 点击"保存到图谱"将结果存入Neo4j

### 4. 产业链图谱

点击导航栏的 **"图谱查询"**:

1. **输入公司名**: 如"华为"、"特斯拉"、"小米"
2. **选择深度**: 选择查询深度(1-4层)
3. **点击查询**: 查看交互式产业链图谱
4. **图谱操作**:
   - 🖱️ 拖拽节点调整位置
   - 🔍 鼠标滚轮缩放
   - 📱 点击全屏按钮
   - 🏷️ 开关"显示关系标签"

### 5. 自动化任务

系统已配置自动化定时任务:
- **每日02:00** - 自动爬取行业新闻
- **每6小时** - 自动更新RSS订阅
- **每周一03:00** - 清理30天前的旧数据

访问 http://localhost:5555 查看Celery任务执行状态。

## 常见问题

### Q1: Docker容器启动失败?

```bash
# 查看错误日志
docker-compose logs backend

# 重启服务
docker-compose restart backend
```

### Q2: 端口被占用?

如果端口冲突,编辑 `docker-compose.yml` 修改端口映射:

```yaml
ports:
  - "8080:80"    # 将前端端口改为8080
  - "8001:8000"  # 将后端端口改为8001
```

### Q3: DeepSeek API报错?

**错误提示**: `AuthenticationError: Invalid API key` 或 `API调用失败`

**解决方法:**

1. 检查 `backend/.env` 中的 API 密钥配置:

```bash
# 进入后端容器检查环境变量
docker exec zhilian-backend env | grep OPENAI
```

2. 确认密钥格式正确:
   - 必须以 `sk-` 开头
   - 完整复制，不要有多余空格
   
3. 验证密钥有效性:
   - 登录 https://platform.deepseek.com/
   - 检查密钥状态是否正常
   - 确认账户余额充足

4. 重启后端服务应用新配置:

```bash
docker-compose restart backend
```

### Q4: 数据库连接失败?

**如果看到数据库连接错误，按以下步骤排查:**

```bash
# 1. 检查 Neo4j 状态和密码
docker exec zhilian-neo4j cypher-shell -u neo4j -p password123 "RETURN 1"

# 2. 检查 MongoDB 状态
docker exec zhilian-mongodb mongosh --eval "db.adminCommand('ping')" -u admin -p password123 --authenticationDatabase admin

# 3. 检查后端连接日志
docker-compose logs backend | grep -i "database\|connection"
```

**如果 Neo4j 密码不对:**
- 方式1: 修改 `backend/.env` 中的 `NEO4J_PASSWORD=password123`
- 方式2: 删除数据卷重新创建: `docker-compose down -v && docker-compose up -d`

### Q5: 前端页面无法访问？

**现象**: 访问 http://localhost 显示无法连接

**解决方法:**

1. 检查容器状态:
```bash
docker-compose ps
# 确认 zhilian-frontend 状态为 Up
```

2. 检查端口占用:
```bash
# Windows
netstat -ano | findstr ":80"

# 如果80端口被占用，修改 docker-compose.yml
# ports: - "8080:80"  # 改用8080端口
```

3. 检查前端日志:
```bash
docker-compose logs frontend
```
