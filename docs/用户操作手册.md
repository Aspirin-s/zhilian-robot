# 智链机器人 - 用户操作手册

## 1. 系统简介

智链机器人是一个基于大语言模型的产业链图谱自动构建平台,能够从文本中自动提取产业链实体和关系,构建可视化的知识图谱。

## 2. 快速开始

### 2.1 访问系统

在浏览器中打开: http://localhost:3000

### 2.2 主要功能

系统提供三大核心功能:

1. **首页** - 查看系统概况和统计信息
2. **图谱查询** - 查询企业产业链关系
3. **文本分析** - 从文本中提取实体和关系

## 3. 功能详解

### 3.1 图谱查询

#### 操作步骤:

1. 点击导航栏的"图谱查询"
2. 在搜索框中输入企业名称
3. 选择查询深度(1-4层)
4. 点击"查询"按钮

#### 功能说明:

- **查询深度**: 控制关系探索的层级
  - 1层: 仅显示直接相关的企业
  - 2层: 显示二度关系
  - 3-4层: 更深层次的产业链网络

- **图谱交互**:
  - 鼠标滚轮: 缩放图谱
  - 拖拽: 移动视图
  - 点击节点: 高亮相关关系

### 3.2 文本分析

#### 操作步骤:

1. 点击导航栏的"文本分析"
2. 在文本框中输入要分析的内容
3. (可选)开启"使用大模型分析"
4. 点击"分析文本"按钮
5. 查看提取的实体和关系
6. 点击"保存到图谱"将结果存入数据库

#### 支持的文本类型:

- 行业新闻报道
- 研究报告
- 企业公告
- 技术文档

#### 提取的信息:

- **实体类型**:
  - 企业名称
  - 产品名称
  - 技术术语
  - 关键人物
  - 地理位置

- **关系类型**:
  - 供应关系
  - 合作关系
  - 竞争关系
  - 投资关系
  - 上下游关系

## 4. 使用场景

### 4.1 产业研究

分析师可以通过文本分析功能,快速从大量行业报告中提取关键信息,构建产业全景图。

### 4.2 投资决策

投资者可以查询目标企业的产业链位置,了解其上下游关系,评估投资风险。

### 4.3 竞争分析

企业可以通过图谱查询,了解竞争对手的合作伙伴和产业布局。

## 5. 最佳实践

### 5.1 文本准备

- 确保文本清晰、结构完整
- 优先使用中文文本
- 文本长度建议500-2000字

### 5.2 查询优化

- 使用准确的企业全称
- 根据需求选择合适的查询深度
- 多次查询可构建更完整的图谱

### 5.3 结果验证

- 检查提取的实体是否准确
- 验证关系的合理性
- 必要时进行人工校正

## 6. 注意事项

1. 首次使用需要先进行文本分析,建立图谱数据
2. 大模型分析功能需要配置API密钥
3. 图谱构建是增量式的,数据会累积
4. 定期清理无效数据以保持图谱质量

## 7. 故障排除

### 问题: 查询无结果

**解决方案**:
- 检查企业名称是否正确
- 确认图谱中已存在该企业数据
- 尝试使用文本分析先建立数据

### 问题: 分析失败

**解决方案**:
- 检查文本格式是否正确
- 确认服务器连接正常
- 查看错误提示信息
