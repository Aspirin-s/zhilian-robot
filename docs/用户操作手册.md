# 智链机器人 - 用户操作手册

## 1. 系统简介

智链机器人是基于 DeepSeek 大模型的产业链图谱自动构建平台,提供数据采集、文本分析和知识图谱可视化功能。

## 2. 访问系统

打开浏览器访问: **http://localhost**

默认包含4个主要页面:
- 首页 - 系统介绍和快速入口
- 数据管理 - RSS订阅和文章管理
- 文本分析 - DeepSeek驱动的NLP分析
- 图谱查询 - 交互式产业链图谱

## 3. 数据管理

### 3.1 RSS订阅管理

系统已预配置4个专业RSS源:
- IEEE Spectrum Robotics
- OFweek机器人网
- TechNode科技
- Robot China机器人网

#### 操作步骤:

1. 点击顶部导航栏的 **"数据管理"**
2. 在 "RSS订阅管理" 区域查看已配置的源
3. 点击 **"立即更新"** 按钮触发数据采集
4. 等待几秒,系统会自动获取最新文章

### 3.2 文章列表

查看已采集的文章:

**功能说明:**
- **标题**: 文章标题
- **来源**: 数据来源(RSS源或爬虫)
- **时间**: 采集时间
- **操作**: 处理/删除单篇文章

**批量操作:**
1. 勾选多篇文章
2. 点击 **"批量处理"** 或 **"批量删除"** 按钮
3. 确认操作

### 3.3 任务历史

查看数据采集任务的执行记录:
- 任务类型
- 执行状态
- 开始/结束时间
- 处理数量

## 4. 图谱探索

### 4.1 搜索企业

1. 点击顶部导航栏的 **"图谱探索"**
2. 在搜索框输入企业名称（如"华为"、"特斯拉"、"小米"）
3. 选择查询层级（1-4层）
4. 点击 **"搜索"** 按钮

### 4.2 交互式 D3 力导向图

**核心特性:**
- **节点拖拽**: 按住鼠标左键拖动节点调整布局
- **画布缩放**: 鼠标滚轮缩放（0.1x-4x）
- **画布平移**: 按住空白区域拖动整个图谱
- **全屏模式**: 点击右上角全屏按钮
- **关系标签**: 切换开关显示/隐藏边标签

**节点交互:**
- **悬停**: 显示节点详细信息（公司名、类型）
- **点击**: 右侧详情面板展示节点属性和关联关系
- **颜色编码**: 
  - 🔵 公司节点（蓝色）
  - 🟢 产品节点（绿色）
  - 🟣 技术节点（紫色）
  - 🟡 人物节点（黄色）
  - 🔴 其他类型（红色）

### 4.3 统计仪表盘

**饼图**: 实体类型分布
- 显示图谱中各类实体的占比
- 交互式图例，点击切换显示

**柱状图**: Top 6 连接数节点
- 按关系数量降序排列
- 快速识别产业链核心节点

**指标卡**:
- 节点总数: 当前图谱实体数量
- 关系总数: 边的数量
- 图密度: 反映图的连接紧密度

### 4.4 实体详情面板

点击节点后，右侧面板显示:
- **基本信息**: 节点名称、类型、标签
- **关联关系**: 
  - 出边: 当前节点指向其他节点的关系
  - 入边: 其他节点指向当前节点的关系
  - 箭头方向可视化（→ 表示出边，← 表示入边）
- **搜索示例**: 快速搜索与该节点相关的其他实体

## 5. 智能分析

### 5.1 输入文本

1. 点击顶部导航栏的 **"智能分析"**
2. 在文本框中输入产业链相关内容（新闻、研报摘要、公司公告等）
3. 或点击 **"加载示例文本"** 查看演示

### 5.2 执行分析

1. 点击 **"分析文本"** 按钮
2. 系统使用 **DeepSeek LLM** 进行智能分析
3. 等待 3-5 秒查看结果

### 5.3 查看结果

**提取的实体** (按类型分组显示):
- 🏢 **公司**: 企业、机构名称（蓝色标签）
- 📦 **产品**: 产品、服务名称（绿色标签）
- 🔧 **技术**: 技术术语、专利名称（紫色标签）
- 👤 **人物**: 关键人物、专家（橙色标签）
- 📍 **地点**: 地理位置、园区（灰色标签）

**提取的关系** (箭头可视化):
- 供应商关系: A → 供应 → B
- 合作关系: A → 合作 → B
- 投资关系: A → 投资 → B
- 竞争关系: A → 竞争 → B
- 其他产业链关系

### 5.4 保存到图谱

1. 检查分析结果准确性
2. 点击 **"保存到图谱"** 按钮
3. 数据自动存入 **Neo4j** 知识图谱
4. 跳转到图谱探索页面查看更新后的图谱

## 8. 技巧与建议

### 8.1 文本分析建议

- **文本长度**: 500-2000字效果最佳
- **内容类型**: 行业报告、新闻资讯、公司介绍
- **语言**: 目前支持中文文本

### 8.2 图谱查询建议

- **查询深度**: 建议从2层开始,3-4层可能较慢
- **节点过多**: 使用全屏模式查看复杂图谱
- **关系标签**: 节点较多时关闭标签,图谱更清晰

### 8.3 数据管理建议

- **定期清理**: 每月清理旧数据,保持系统性能
- **批量操作**: 一次处理不超过50篇文章
- **RSS更新**: 每天手动更新1-2次即可

## 9. 故障排查

### 问题1: 文本分析失败

**可能原因:**
- DeepSeek API密钥未配置或过期
- 网络连接问题

**解决方法:**
1. 检查 `backend/.env` 中的 API 密钥
2. 查看后端日志: `docker-compose logs backend`
3. 重启后端服务: `docker-compose restart backend`

### 问题2: 图谱显示空白

**可能原因:**
- Neo4j 数据库中没有数据
- 查询的公司不存在

**解决方法:**
1. 先通过"文本分析"功能添加数据
2. 确认公司名称正确
3. 访问 Neo4j 界面检查数据

### 问题3: RSS更新无响应

**可能原因:**
- Celery Worker 未运行
- Redis 连接失败

**解决方法:**
1. 检查容器状态: `docker-compose ps`
2. 查看 Celery 日志: `docker-compose logs celery-worker`
3. 重启服务: `docker-compose restart celery-worker redis`
