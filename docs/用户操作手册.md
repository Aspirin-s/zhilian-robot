# 智链机器人 - 用户操作手册

## 1. 系统简介

智链机器人是基于 DeepSeek 大模型的产业链图谱自动构建平台,提供数据采集、文本分析和知识图谱可视化功能。

## 2. 访问系统

打开浏览器访问: **http://localhost**

默认包含4个主要页面:
- 首页 - 系统介绍和快速入口
- 数据管理 - RSS订阅和文章管理
- 文本分析 - DeepSeek驱动的NLP分析
- 图谱查询 - 交互式产业链图谱

## 3. 数据管理

### 3.1 RSS订阅管理

系统已预配置4个专业RSS源:
- IEEE Spectrum Robotics
- OFweek机器人网
- TechNode科技
- Robot China机器人网

#### 操作步骤:

1. 点击顶部导航栏的 **"数据管理"**
2. 在 "RSS订阅管理" 区域查看已配置的源
3. 点击 **"立即更新"** 按钮触发数据采集
4. 等待几秒,系统会自动获取最新文章

### 3.2 文章列表

查看已采集的文章:

**功能说明:**
- **标题**: 文章标题
- **来源**: 数据来源(RSS源或爬虫)
- **时间**: 采集时间
- **操作**: 处理/删除单篇文章

**批量操作:**
1. 勾选多篇文章
2. 点击 **"批量处理"** 或 **"批量删除"** 按钮
3. 确认操作

### 3.3 任务历史

查看数据采集任务的执行记录:
- 任务类型
- 执行状态
- 开始/结束时间
- 处理数量

## 4. 文本分析

### 4.1 输入文本

1. 点击顶部导航栏的 **"文本分析"**
2. 在文本框中输入产业链相关内容
3. 或点击 **"加载示例文本"** 查看演示

### 4.2 执行分析

1. 点击 **"分析文本"** 按钮
2. 系统使用 DeepSeek 大模型进行分析
3. 等待几秒钟查看结果

### 4.3 查看结果

**提取的实体:**
- 企业: 公司名称
- 产品: 产品名称
- 技术: 技术术语
- 人物: 关键人物
- 地点: 地理位置

**提取的关系:**
- 主体 - 关系类型 - 客体
- 置信度评分

### 4.4 保存到图谱

1. 分析完成后,点击 **"保存到图谱"** 按钮
2. 系统将实体和关系存入 Neo4j 图数据库
3. 查看保存统计信息

## 5. 产业链图谱查询

### 5.1 查询操作

1. 点击顶部导航栏的 **"图谱查询"**
2. 输入公司名称,如:
   - 华为
   - 特斯拉
   - 小米
3. 选择查询深度(1-4层):
   - 1层: 直接关系
   - 2层: 二度关系
   - 3-4层: 更深层次网络
4. 点击 **"查询"** 按钮

或点击示例按钮快速查询:
- 示例: 特斯拉
- 示例: 华为
- 示例: 小米

### 5.2 图谱交互

**鼠标操作:**
- **拖拽节点**: 调整节点位置
- **滚轮缩放**: 放大/缩小图谱
- **悬停查看**: 鼠标悬停在节点或边上查看详情

**工具栏按钮:**
- **显示关系标签**: 开关控制连线上的标签显示
- **全屏显示**: 进入/退出全屏模式(按ESC退出)

**节点颜色:**
- 🔵 蓝色 - 企业(companies)
- 🟢 绿色 - 产品(products)
- 🟡 黄色 - 技术(technologies)
- 🔴 红色 - 人物(persons)
- 🔵 青色 - 地点(locations)

### 5.3 图谱说明

- 节点大小固定,便于识别
- 边的弯曲度优化,避免重叠
- 自动去重相同关系的连线
- 力导向布局自动调整位置

## 7. 常见操作

### 7.1 手动触发RSS更新

1. 进入"数据管理"页面
2. 点击"立即更新"按钮
3. 等待任务完成
4. 刷新文章列表查看新数据

### 7.2 批量处理文章

1. 在文章列表中勾选多篇文章
2. 点击"批量处理"按钮
3. 系统使用DeepSeek分析所有选中文章
4. 自动保存到图谱

### 7.3 导出图谱数据

目前支持通过 Neo4j 界面导出:

1. 访问 http://localhost:7474
2. 登录(用户名: neo4j, 密码: password123)
3. 使用 Cypher 查询导出数据

### 7.4 清理旧数据

使用 API 清理过期数据:

```bash
# 清理30天前的数据
curl -X DELETE "http://localhost:8000/api/v1/data/cleanup?days=30"
```

## 8. 技巧与建议

### 8.1 文本分析建议

- **文本长度**: 500-2000字效果最佳
- **内容类型**: 行业报告、新闻资讯、公司介绍
- **语言**: 目前支持中文文本

### 8.2 图谱查询建议

- **查询深度**: 建议从2层开始,3-4层可能较慢
- **节点过多**: 使用全屏模式查看复杂图谱
- **关系标签**: 节点较多时关闭标签,图谱更清晰

### 8.3 数据管理建议

- **定期清理**: 每月清理旧数据,保持系统性能
- **批量操作**: 一次处理不超过50篇文章
- **RSS更新**: 每天手动更新1-2次即可

## 9. 故障排查

### 问题1: 文本分析失败

**可能原因:**
- DeepSeek API密钥未配置或过期
- 网络连接问题

**解决方法:**
1. 检查 `backend/.env` 中的 API 密钥
2. 查看后端日志: `docker-compose logs backend`
3. 重启后端服务: `docker-compose restart backend`

### 问题2: 图谱显示空白

**可能原因:**
- Neo4j 数据库中没有数据
- 查询的公司不存在

**解决方法:**
1. 先通过"文本分析"功能添加数据
2. 确认公司名称正确
3. 访问 Neo4j 界面检查数据

### 问题3: RSS更新无响应

**可能原因:**
- Celery Worker 未运行
- Redis 连接失败

**解决方法:**
1. 检查容器状态: `docker-compose ps`
2. 查看 Celery 日志: `docker-compose logs celery-worker`
3. 重启服务: `docker-compose restart celery-worker redis`
