## 🚀 使用流程

### 开发环境启动
```powershell
# 1. 初始化
.\scripts\init.ps1

# 2. 启动服务
.\scripts\start.ps1
```

### Docker部署
```bash
# 一键启动
docker-compose up -d

# 查看状态
docker-compose ps

# 查看日志
docker-compose logs -f
```

### 访问系统
- 前端: http://localhost:3000
- 后端: http://localhost:8000
- API文档: http://localhost:8000/docs
