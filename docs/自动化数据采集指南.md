# 自动化数据采集指南

## 1. 功能概述

智链机器人提供全自动化的数据采集和图谱更新功能,无需人工干预即可持续扩充产业链知识库。

### 1.1 核心特性

**多源数据采集:**
- RSS 订阅源(4个预配置源)
- 机器人行业新闻网站
- 科技资讯平台
- 可扩展的爬虫框架

**自动定时任务:**
- 每日凌晨 02:00 爬取行业新闻
- 每 6 小时更新 RSS 订阅
- 每周一凌晨 03:00 清理 30 天前的旧数据

**智能增量更新:**
- 自动去重,避免重复采集
- 实体关系置信度更新
- 统计实体/关系出现次数

**实时监控:**
- Celery Flower 监控面板
- 任务执行历史记录
- 数据源统计分析

## 5. 新闻爬虫

爬虫代码位于 `backend/app/services/spider_service.py`。

**当前爬取目标:**
- 机器人行业网站
- 自动化设备新闻

## 6. 数据处理流程

### 6.1 自动处理流程

```
采集数据 → MongoDB → Celery任务 → DeepSeek分析 → Neo4j图谱
```

**详细步骤:**

1. **数据采集**: RSS/爬虫获取原始文章
2. **存储**: 保存到 MongoDB
3. **队列**: Celery Beat 定期检查未处理文章
4. **分析**: DeepSeek 提取实体和关系
5. **保存**: 存入 Neo4j 图数据库
6. **更新**: 标记文章为已处理

### 6.2 批量处理

**API 批量处理:**


## 9. 故障排查

### 问题1: Celery Worker 未启动

**症状:** Flower 显示无 Worker 连接

**解决方法:**

```bash
# 检查容器状态
docker-compose ps celery-worker

# 查看日志
docker-compose logs celery-worker

# 重启服务
docker-compose restart celery-worker
```

### 问题2: 定时任务不执行

**症状:** 任务未按时执行

**解决方法:**

```bash
# 检查 Celery Beat 状态
docker-compose ps celery-beat

# 查看 Beat 日志
docker-compose logs -f celery-beat

# 确认时区设置
docker-compose exec celery-beat date
```

### 问题3: RSS 更新失败

**症状:** RSS 任务失败,Flower 显示错误

**可能原因:**
- 网络连接问题
- RSS 源地址失效
- 解析错误

**解决方法:**

1. 检查网络: `ping spectrum.ieee.org`
2. 手动访问 RSS URL 验证可用性
3. 查看错误日志: `docker-compose logs celery-worker | grep ERROR`
4. 更新 RSS 源配置

### 问题4: 爬虫被封禁

**症状:** 爬虫任务失败,返回 403/429 错误

**解决方法:**

1. 增加请求间隔(改为 3-5 秒)
2. 使用代理 IP
3. 更换 User-Agent
4. 降低爬取频率

## 10. 高级配置

### 10.1 并发数调整

编辑 `docker-compose.yml`:

```yaml
celery-worker:
  command: celery -A app.tasks.celery_app worker --loglevel=info --concurrency=4
  # concurrency=4 表示4个并发进程
```

### 10.2 任务优先级

在 Celery 任务中设置优先级:

```python
@celery_app.task(priority=9)  # 0-9,9最高
def urgent_task():
    pass

@celery_app.task(priority=5)
def normal_task():
    pass
```

### 10.3 任务重试

配置任务失败重试:

```python
@celery_app.task(
    autoretry_for=(Exception,),
    retry_kwargs={'max_retries': 3, 'countdown': 60}
)
def reliable_task():
    pass
```
