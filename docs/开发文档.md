# 智链机器人 - 开发文档

## 1. 开发环境设置

### 1.1 前置要求

- Docker Desktop 4.0+ (Windows/Mac) 或 Docker Engine 20.10+ (Linux)
- Docker Compose 2.0+
- Git
- 代码编辑器 (推荐 VS Code)

### 1.2 克隆项目

```bash
git clone https://github.com/Aspirin-s/zhilian-robot.git
cd zhilian-robot
```

### 1.3 配置环境变量

复制并编辑环境配置文件:

```bash
# 后端配置
cd backend
copy .env.example .env
# 编辑 .env 文件,填入 DeepSeek API 密钥
```

必须配置的环境变量:

```env
DEEPSEEK_API_KEY=sk-xxxxxxxxxxxxx
DEEPSEEK_BASE_URL=https://api.deepseek.com
```

### 1.4 启动开发环境

```bash
# 返回项目根目录
cd ..

# 构建并启动所有容器
docker-compose up -d

# 查看容器状态
docker-compose ps
```

等待几分钟,确保所有9个容器运行正常。

## 2. 项目架构

### 2.1 技术栈

**前端:**
- React 18.2.0
- Ant Design 5.11.5（深色主题）
- **D3.js 7.9.0**（力导向图可视化）
- **Recharts 2.15.4**（统计图表）
- Vite 5.4.21（构建工具）
- Axios 1.6.2（HTTP客户端）
- React Router 6.20.0（路由）

**后端:**
- FastAPI 0.104.1（Web框架）
- **OpenAI SDK 1.57.0**（DeepSeek API）
- Celery 5.3.4（异步任务队列）
- Scrapy 2.11.0（爬虫框架）
- Feedparser 6.0.10（RSS解析）

**数据存储:**
- Neo4j 5.20（图数据库）
- MongoDB 8.0（文档数据库）
- MySQL 8.0（关系数据库）
- Redis 7-alpine（缓存和消息队列）

**部署:**
- Docker Compose（9 容器编排）
- Nginx alpine（反向代理）
- wait_for_db.py（数据库初始化等待）

## 3. 开发指南

### 3.1 前端开发

#### 启动开发服务器

```bash
cd frontend
npm install
npm run dev
```

前端开发服务器运行在 `http://localhost:5173`

#### 添加新页面

1. 在 `frontend/src/pages/` 创建新组件
2. 在 `frontend/src/App.jsx` 添加路由

示例:

```jsx
// frontend/src/pages/NewPage.jsx
import React from 'react';

const NewPage = () => {
  return (
    <div>
      <h1>新页面</h1>
    </div>
  );
};

export default NewPage;
```

```jsx
// frontend/src/App.jsx
import NewPage from './pages/NewPage';

// 在路由配置中添加
<Route path="/new" element={<NewPage />} />
```

#### 调用后端 API

使用 `frontend/src/api/api.js` 封装的方法:

```jsx
import { analysisApi } from '../api/api';

const handleAnalyze = async () => {
  try {
    const response = await analysisApi.analyzeText({
      text: '文本内容',
      use_llm: true
    });
    console.log(response.data);
  } catch (error) {
    console.error('分析失败:', error);
  }
};
```

### 3.2 后端开发

#### 启动开发服务器

```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

后端 API 运行在 `http://localhost:8000`

#### 添加新 API 端点

1. 在 `backend/app/api/v1/` 创建新路由文件
2. 在 `backend/app/main.py` 注册路由

示例:

```python
# backend/app/api/v1/example.py
from fastapi import APIRouter

router = APIRouter()

@router.post("/process")
async def process_data(data: dict):
    """处理数据"""
    return {"status": "success", "data": data}
```

```python
# backend/app/main.py
from app.api.v1 import example

app.include_router(example.router, prefix="/api/v1/example", tags=["example"])
```

#### 访问数据库

**Neo4j:**

```python
from app.services.neo4j_service import Neo4jService

neo4j = Neo4jService()
results = neo4j.query("MATCH (n:Company) RETURN n LIMIT 10")
```

**MongoDB:**

```python
from app.services.mongodb_service import MongoDBService

mongodb = MongoDBService()
articles = mongodb.get_articles(limit=10)
```

#### 创建异步任务

在 `backend/app/tasks/celery_tasks.py` 添加任务:

```python
from app.tasks.celery_app import celery_app

@celery_app.task
def process_article(article_id: str):
    """处理单篇文章"""
    # 任务逻辑
    return {"article_id": article_id, "status": "processed"}
```

调用任务:

```python
from app.tasks.celery_tasks import process_article

# 异步执行
task = process_article.delay("article_123")

# 获取结果
result = task.get()
```

## 7. 常见问题

### 问题1: 容器启动失败

检查端口是否被占用:

```bash
# Windows PowerShell
netstat -ano | findstr "7474"
netstat -ano | findstr "27017"
```

### 问题2: DeepSeek API 调用失败

1. 检查 API 密钥是否正确
2. 检查网络连接
3. 查看后端日志: `docker-compose logs backend`

### 问题3: 数据库连接失败

1. 确认容器已启动: `docker-compose ps`
2. 检查网络配置: `docker network ls`
3. 重启相关容器: `docker-compose restart`
