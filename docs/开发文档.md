# 智链机器人 - 开发文档

## 1. 环境准备

### 1.1 必需软件

- Python 3.8+
- Node.js 16+
- Docker & Docker Compose (可选)

### 1.2 数据库准备

**方案一:使用Docker(推荐)**

```bash
docker-compose up -d neo4j mongodb redis mysql
```

**方案二:本地安装**

- Neo4j 5.20+
- MongoDB 8.x
- Redis 7.x+
- MySQL 8.x

## 2. 后端开发

### 2.1 安装依赖

```bash
cd backend
pip install -r requirements.txt
```

### 2.2 配置环境变量

复制 `.env.example` 为 `.env`,修改配置:

```bash
cp .env.example .env
```

编辑 `.env` 文件,配置数据库连接和API密钥。

### 2.3 启动后端服务

```bash
python main.py
```

访问: http://localhost:8000
API文档: http://localhost:8000/docs

## 3. 前端开发

### 3.1 安装依赖

```bash
cd frontend
npm install
```

### 3.2 启动开发服务器

```bash
npm run dev
```

访问: http://localhost:3000

### 3.3 构建生产版本

```bash
npm run build
```

## 5. 核心功能模块

### 5.1 NLP处理模块

- **NER(命名实体识别)**: `app/nlp/ner.py`
- **RE(关系抽取)**: `app/nlp/re.py`
- **LLM集成**: `app/nlp/llm.py`

### 5.2 数据库模块

- **Neo4j**: 图数据库,存储产业链图谱
- **MongoDB**: 文档数据库,存储原始文本
- **Redis**: 缓存层,加速查询
- **MySQL**: 关系数据库,存储用户信息

### 5.3 爬虫模块

基于Scrapy框架,支持:
- 新闻资讯爬取
- 研究报告采集
- 企业信息收集

### 5.4 图谱构建

- 实体提取与存储
- 关系识别与建立
- 图谱动态更新

## 6. API接口

### 6.1 NLP接口

- `POST /api/v1/nlp/analyze` - 分析文本
- `POST /api/v1/nlp/analyze-llm` - 使用大模型分析
- `GET /api/v1/nlp/entities/categories` - 获取实体类别
- `GET /api/v1/nlp/relations/types` - 获取关系类型

### 6.2 图谱接口

- `POST /api/v1/graph/build` - 构建图谱
- `POST /api/v1/graph/query` - 查询产业链
- `GET /api/v1/graph/company/{name}` - 查询企业关系
- `GET /api/v1/graph/statistics` - 获取统计信息

## 9. 常见问题

### 9.1 数据库连接失败

检查配置文件中的数据库地址和端口是否正确。

### 9.2 模型加载缓慢

首次运行会下载模型,请耐心等待或配置本地模型路径。

### 9.3 CORS错误

检查后端配置中的CORS_ORIGINS是否包含前端地址。
