## 核心功能模块

### 1. NLP模块
```
app/nlp/
├── ner.py          # 命名实体识别
│   ├── NERProcessor
│   ├── extract_entities()
│   └── extract_industry_entities()
│
├── re.py           # 关系抽取
│   ├── REProcessor
│   ├── extract_relations()
│   └── extract_supply_chain_relations()
│
└── llm.py          # 大模型集成
    ├── LLMProcessor
    ├── extract_entities_with_llm()
    └── extract_relations_with_llm()
```

### 2. 图谱模块
```
app/services/
└── graph_service.py
    ├── build_graph_from_text()
    ├── query_industry_chain()
    ├── _save_to_graph()
    └── get_graph_statistics()
```

### 3. 数据库模块
```
app/database/
├── neo4j_db.py     # Neo4j连接
├── mongodb.py      # MongoDB连接
├── redis_db.py     # Redis连接
└── __init__.py     # 统一初始化
```

### 4. API模块
```
app/api/
├── nlp_routes.py   # NLP接口
│   ├── POST /api/v1/nlp/analyze
│   ├── POST /api/v1/nlp/analyze-llm
│   ├── GET  /api/v1/nlp/entities/categories
│   └── GET  /api/v1/nlp/relations/types
│
└── graph_routes.py # 图谱接口
    ├── POST   /api/v1/graph/build
    ├── POST   /api/v1/graph/query
    ├── GET    /api/v1/graph/company/{name}
    ├── GET    /api/v1/graph/statistics
    └── DELETE /api/v1/graph/clear
```
